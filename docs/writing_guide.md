# 经济学论文写作指南

本文档提供经济学论文从选题到投稿的完整指导。

## 一、选题与研究设计

### 1.1 选题标准

好的研究问题应满足以下标准：

| 标准 | 说明 | 示例 |
|------|------|------|
| 重要性 | 对现实或理论有重要意义 | 气候变化对经济的影响 |
| 可回答 | 在资源和时间内可回答 | 利用现有调查数据可检验 |
| 有趣 | 其他研究者会关心 | 挑战主流理论或发现新现象 |
| 可推广 | 发现具有更广泛的意义 | 发现普遍机制而非特例 |

### 1.2 选题来源

1. **现实问题**: 经济现象、政策争议、社会热点
2. **文献缺口**: 现有研究的争议、未充分探讨的问题
3. **数据驱动**: 新数据可用带来的研究机会
4. **方法创新**: 新计量方法应用
5. **跨领域**: 其他学科理论与经济学结合

### 1.3 研究设计框架

```
研究设计 = 理论框架 + 数据 + 方法 + 识别策略
```

**理论框架**: 解释变量X如何影响被解释变量Y

**数据**: 来源、时间跨度、样本量、数据质量

**方法**: 计量经济学方法选择

**识别策略**: 如何建立因果关系而非相关关系

## 二、论文结构

### 2.1 标准结构（实证论文）

| 部分 | 内容 | 篇幅占比 |
|------|------|----------|
| 引言 | 背景、问题、贡献 | 15-20% |
| 文献综述 | 理论、文献、假说 | 20-25% |
| 数据与方法 | 数据、变量、模型 | 20-25% |
| 实证结果 | 基准、稳健、异质 | 25-30% |
| 结论 | 发现、建议、局限 | 10-15% |

### 2.2 各部分写作要点

#### 引言（Introduction）

**五段式结构**:

```
[段落1: 背景] 近年来，X现象日益突出...
[段落2: 已有研究] 学者A(2020)发现...，学者B(2021)指出...
[段落3: 研究缺口] 然而，现有研究忽视了...，关于...尚无一致结论
[段落4: 本文研究] 本文利用...数据，采用...方法，检验...
[段落5: 主要发现] 研究发现X对Y有显著的正向影响，贡献在于...
```

**引言检查清单**:
- [ ] 研究背景清晰，重要性明确
- [ ] 研究问题具体、可回答
- [ ] 文献定位准确
- [ ] 主要发现简洁有力
- [ ] 文章结构清晰

#### 文献综述（Literature Review）

**四步法**:

1. **界定概念**: 核心术语的定义和边界
2. **建立理论**: 解释变量影响被解释变量的机制
3. **回顾文献**: 梳理相关实证研究（按主题或时间）
4. **指出缺口**: 现有研究的不足和本文的定位

**文献评述模板**:

```
[学者A, 年份] 研究发现X对Y有正向影响，
但是主要关注[特定群体/时期/情境]。
[学者B, 年份] 利用[数据/方法]检验了类似问题，
结果发现[不一致的发现]。
本文将填补这一空白，利用[新数据/新方法]检验...
```

#### 数据与研究方法

**数据部分必须包含**:

- 数据来源（官方统计、调查数据、企业数据等）
- 时间跨度与样本范围
- 数据处理过程（缺失值、极端值处理）
- 变量定义表格

**方法部分必须包含**:

- 模型设定（基准回归方程）
- 变量选择依据
- 内生性处理方案
- 稳健性检验设计

**示例**:

```
本文使用2010-2020年中国家庭追踪调查(CFPS)数据，
包含31个省份25000户家庭的面板数据。
被解释变量Y定义为家庭人均消费支出（取对数），
核心解释变量X定义为户主受教育年限。
控制变量包括：家庭人口规模、收入、资产、地区特征等。

由于X可能存在内生性问题（遗漏变量、反向因果），
我们采用工具变量法，使用[工具变量选择理由]
作为X的工具变量...
```

#### 实证结果

**呈现原则**:

1. 从简单到复杂，逐步增加控制变量和固定效应
2. 每张表格要有明确的主题和"故事"
3. 表格下方要有完整的注释

**回归结果解读模板**:

```
"表2报告了基准回归结果。第(1)列仅包含核心解释变量，
系数为0.123，且在1%水平显著，表明X对Y有显著的正向影响。
具体而言，X每增加1个单位，Y平均增加12.3%。
加入控制变量后（第(2)列），核心解释变量系数略有下降（0.098），
但仍在1%水平显著，表明在控制其他因素后，X对Y的影响依然稳健。
加入双向固定效应后（第(3)列），系数进一步调整为0.087，
仍在5%水平显著，说明上述关系不受地区和时间异质性影响。"
```

#### 结论

**结论写作要点**:

- 只总结有实证支持的发现
- 政策建议要有依据
- 承认局限性，不夸大贡献
- 指出未来研究方向

**常见错误**:

- ❌ 重复摘要内容
- ❌ 提出没有实证支持的结论
- ❌ 夸大研究贡献
- ❌ 遗漏重要局限性

## 三、常用计量方法

### 3.1 面板数据

```stata
// 双向固定效应
xtreg y x controls i.year, fe

// 随机效应
xtreg y x controls, re

// Hausman检验
xttest0
```

### 3.2 双重差分（DID）

```stata
// 事件研究法
reg y treatment##post controls, robust

// 平行趋势检验
gen relative_time = year - shock_year
reg y i.relative_time if inrange(relative_time, -3, 3), robust
```

### 3.3 工具变量法

```stata
// 两阶段最小二乘
ivreg2 y controls (x = z1 z2), gmm2s robust

// 检验
estat firststage  // F > 10 无弱工具变量
estat overid       // Sargan检验
```

### 3.4 断点回归

```stata
// 精确RDD
rdrobust y running, c(cutoff)

// 带宽选择
rdbwselect y running, c(cutoff)
```

## 四、语言与表达

### 4.1 学术写作规范

| ❌ 避免 | ✅ 推荐 |
|--------|--------|
| "As we can see from Figure 1" | "Figure 1 shows" |
| "This is a very interesting finding" | "This finding suggests" |
| "The reason is because" | "This result reflects" |
| "In order to" | "To" |

### 4.2 计量结果表述

| 类型 | 示例 |
|------|------|
| 正向关系 | "X is positively associated with Y" |
| 负向关系 | "X is negatively related to Y" |
| 显著性 | "significant at the 1% level" |
| 系数解读 | "a one-unit increase in X is associated with a 0.12 increase in Y" |

### 4.3 常见格式错误

| 错误 | 正确 |
|------|------|
| p < .05 | p < 0.05 |
| N=100 | N = 100 |
| ten percent | 10 percent 或 10\% |
| six observations | six observations（1-9用英文） |
| fig. 1 | Figure 1 |

## 六、匿名处理检查清单

**必须删除**:

- 作者姓名和机构信息
- 致谢和基金信息
- 可识别作者身份的文献引用
- 自我引用

**可以保留**:

- 变量名和模型设定
- 理论框架描述
- 计量方法说明

## 七、投稿流程

1. 选择期刊（根据质量、主题匹配度）
2. 按期刊格式调整
3. 写cover letter（说明贡献和适合性）
4. 通过投稿系统提交
5. 等待审稿（通常4-8周）
6. 认真回应审稿意见
7. 最终校对后接受
