## 数据使用注意事项

1. **注册与申请**: 大多数数据库需要注册，部分需要申请使用权限
2. **引用规范**: 使用数据时务必引用官方说明文档
3. **版本更新**: 定期检查数据更新，确保使用最新版本
4. **缺失值说明**: 论文中需说明数据缺失情况及处理方法
5. **样本限制**: 注意数据库的使用范围和限制条款
