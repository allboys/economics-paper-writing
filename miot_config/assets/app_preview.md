# 应用预览材料规范

## 截图要求

### 应用商店截图

| 类型 | 尺寸 | 数量 | 说明 |
|------|------|------|------|
| 手机截图 | 1080 x 1920 px | 3-5张 | 展示核心功能 |
| 平板截图 | 2048 x 2732 px | 2-3张 | 可选 |
| 概览图 | 1024 x 500 px | 1张 | 应用商店头部 |

### 截图内容建议

1. **主界面**: 展示论文列表和快速操作
2. **编辑器**: 展示 Markdown/LaTeX 写作界面
3. **文献管理**: 展示文献库和引用功能
4. **AI助手**: 展示智能润色和语法检查
5. **设置页**: 展示同步和云端配置

### 设计规范

- 深色模式: 使用深色背景 (#1a1a2e)
- 浅色模式: 使用浅色背景 (#ffffff)
- 状态栏: 显示时间、电量（模拟数据）
- 导航栏: 隐藏或使用应用内导航
