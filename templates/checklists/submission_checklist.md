# 投稿前检查清单

## 初稿完成
- [ ] 引言清晰阐述研究问题
- [ ] 文献综述完整覆盖相关研究
- [ ] 方法论描述详细可复现
- [ ] 结果解释合理
- [ ] 结论与实证发现一致

## 格式检查
- [ ] 遵循期刊格式要求
- [ ] 标题页完整（含所有作者信息）
- [ ] 摘要符合字数要求
- [ ] 关键词数量正确
- [ ] 参考文献格式统一

## 图表检查
- [ ] 图表编号连续
- [ ] 图表标题清晰
- [ ] 数据来源标注
- [ ] 所有图表在正文中引用

## 数学与统计
- [ ] 公式编号正确
- [ ] 符号使用一致
- [ ] 表格小数点对齐
- [ ] 标准误/置信区间报告

## 语言检查
- [ ] 无语法错误
- [ ] 学术表达规范
- [ ] 检查 [ ] 使用，避免中英混杂

## 引用检查
- [ ] 所有引用都有对应文献
- [ ] 文献列表无遗漏
- [ ] 引用格式符合期刊要求

## 常见错误
- [ ] 避免 "As shown in Figure 1" (用 Figure \ref{fig:1})
- [ ] 避免 "We can see from Table 2" (用 Table \ref{tab:2})
- [ ] P值格式: p < 0.01, 不是 p<.01
- [ ] 数字: one to nine 用英文, 10+ 用阿拉伯数字
