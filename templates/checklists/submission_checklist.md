# 经济学论文检查清单

> 投稿前请逐项核对

---

## 一、内容完整性

### 引言
- [ ] 研究背景清晰，重要性明确
- [ ] 研究问题具体、可回答
- [ ] 文献定位准确（本文与已有研究的关系）
- [ ] 主要发现已报告（包含关键数字）
- [ ] 研究贡献明确（理论/实证/政策）
- [ ] 文章结构说明完整

### 文献综述
- [ ] 核心概念界定清晰
- [ ] 理论基础完整
- [ ] 相关文献覆盖全面
- [ ] 文献评述到位（指出缺口）
- [ ] 研究假说有依据

### 数据与方法
- [ ] 数据来源明确
- [ ] 样本范围清晰
- [ ] 变量定义完整（表格）
- [ ] 模型设定合理
- [ ] 识别策略清晰
- [ ] 内生性处理方案明确

### 实证结果
- [ ] 基准回归完整
- [ ] 稳健性检验充分（至少3种）
- [ ] 异质性分析有深度
- [ ] 机制检验可信（如有）
- [ ] 表格注释完整
- [ ] 结果解读与发现一致

### 结论
- [ ] 主要发现不重复摘要
- [ ] 政策建议有实证依据
- [ ] 研究局限诚实
- [ ] 未来方向有价值

---

## 二、格式规范

### 页面格式
- [ ] 页边距符合要求（通常1英寸）
- [ ] 字体大小合适（12pt）
- [ ] 行距符合要求（双倍行距或期刊要求）
- [ ] 页码正确

### 标题页
- [ ] 标题居中、加粗
- [ ] 作者姓名完整
- [ ] 机构信息完整
- [ ] 脚注（致谢、基金项目）已匿名化

### 摘要
- [ ] 字数符合要求（150-300字）
- [ ] 包含：问题、方法、发现、结论
- [ ] 关键词3-5个
- [ ] JEL分类号正确

### 表格与图表
- [ ] 编号连续（图1, 图2, 表1, 表2）
- [ ] 标题清晰（表格在上，图片在下）
- [ ] 数据来源标注
- [ ] 显著性标注正确 (*, **, ***)
- [ ] 标准误/置信区间完整
- [ ] 表格边框符合期刊要求
- [ ] 小数点对齐

### 参考文献
- [ ] 格式统一（期刊要求）
- [ ] 无遗漏文献
- [ ] 文中引用与文献列表一致
- [ ] DOI已添加（如有）

---

## 三、语言表达

### 语法与拼写
- [ ] 无语法错误
- [ ] 无拼写错误
- [ ] 无打字错误

### 学术表达
- [ ] 用词专业、准确
- [ ] 无口语化表达
- [ ] 无中英混杂（除非专有名词）

### 常见错误检查
- [ ] "Figure 1" 不是 "figure 1" 或 "fig. 1"
- [ ] "Table 1" 不是 "table 1"
- [ ] p值格式: p < 0.05 不是 p<.05
- [ ] 数字1-9用英文: six observations
- [ ] 数字10+用阿拉伯数字: 10 observations

### 引用格式
- [ ] 作者(年份)格式一致
- [ ] 无多余空格
- [ ] 无自我引用（匿名审稿）

---

## 四、匿名处理

### 必须删除
- [ ] 作者姓名
- [ ] 机构信息（标题页和正文）
- [ ] 致谢部分
- [ ] 基金项目信息
- [ ] 作者联系方式
- [ ] 自我引用（改为"作者等，年份"）

### 可以保留
- [ ] 变量名和模型设定
- [ ] 理论框架描述
- [ ] 计量方法说明
- [ ] 数据来源描述

---

## 五、常见错误清单

### 数据处理
- [ ] 缺失值处理说明
- [ ] 极端值处理说明
- [ ] 数据来源可靠

### 计量方法
- [ ] 基准模型设定合理
- [ ] 固定效应选择有理由
- [ ] 聚类层级正确
- [ ] 内生性处理方案可行

### 结果解读
- [ ] 因果 vs 相关 表述准确
- [ ] 系数解读正确（单位变化带来的变化）
- [ ] 统计显著 vs 经济显著 区分
- [ ] 不过度推断

### 图表制作
- [ ] 图表清晰可读
- [ ] 字体大小合适
- [ ] 颜色区分清楚（黑白打印可辨识）
- [ ] 坐标轴标签完整

- [ ] 文献覆盖全面
- [ ] 结论不过度
